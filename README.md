# 🌍 Mi Segundo Repositorio: Hola Mundo en Múltiples Lenguajes

¡Bienvenido a mi segundo repositorio! 🎉

Este proyecto contiene ejemplos del clásico programa **"Hola Mundo"** implementado en diversos lenguajes de programación, demostrando la sintaxis básica y estructura de cada uno.

---

## 📚 Lenguajes Incluidos

| Lenguaje | Archivo | ¿Cómo ejecutarlo? |
| :--- | :--- | :--- |
| **Python** | [`python/hola_mundo.py`](./python/hola_mundo.py) | `python hola_mundo.py` |
| **JavaScript (Node.js)** | [`javascript/hola_mundo.js`](./javascript/hola_mundo.js) | `node hola_mundo.js` |
| **TypeScript** | [`typescript/hola_mundo.ts`](./typescript/hola_mundo.ts) | `ts-node hola_mundo.ts` |
| **C** | [`c/hola_mundo.c`](./c/hola_mundo.c) | `gcc hola_mundo.c -o hola && ./hola` |
| **C++** | [`cpp/hola_mundo.cpp`](./cpp/hola_mundo.cpp) | `g++ hola_mundo.cpp -o hola && ./hola` |
| **Java** | [`java/HolaMundo.java`](./java/HolaMundo.java) | `javac HolaMundo.java && java HolaMundo` |
| **C#** | [`csharp/Program.cs`](./csharp/Program.cs) | `dotnet run` |
| **Go** | [`go/main.go`](./go/main.go) | `go run main.go` |
| **Rust** | [`rust/main.rs`](./rust/main.rs) | `rustc main.rs && ./main` |
| **PHP** | [`php/hola_mundo.php`](./php/hola_mundo.php) | `php hola_mundo.php` |
| **Ruby** | [`ruby/hola_mundo.rb`](./ruby/hola_mundo.rb) | `ruby hola_mundo.rb` |
| **Kotlin** | [`kotlin/hola_mundo.kt`](./kotlin/hola_mundo.kt) | `kotlinc hola_mundo.kt -include-runtime -d hola.jar && java -jar hola.jar` |
| **Swift** | [`swift/hola_mundo.swift`](./swift/hola_mundo.swift) | `swift hola_mundo.swift` |
| **Bash** | [`bash/hola_mundo.sh`](./bash/hola_mundo.sh) | `bash hola_mundo.sh` |
| **SQL** | [`sql/hola_mundo.sql`](./sql/hola_mundo.sql) | Ejecutar en cualquier gestor SQL (PostgreSQL, MySQL, SQLite) |
| **HTML** | [`html/index.html`](./html/index.html) | Abrir directamente en el navegador |
